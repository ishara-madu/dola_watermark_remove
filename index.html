Quick Start Guide

How to Install in 5 Simple Steps

No Chrome Web Store wait required. Install manually via Chromium Developer Mode in under 60 seconds.

01

Download & Extract ZIP

Click the download button to save dola-watermark-remover.zip on your computer. Extract the ZIP file to reveal the extension folder.

02

Open Chrome Extensions Page

Open a new tab in your Chromium browser (Chrome, Brave, or Edge), and navigate to chrome://extensions in the address bar.

chrome://extensions
03

Enable Developer Mode & Click Load Unpacked

In the top right corner of the extensions page, toggle on Developer mode. Then click the Load unpacked button located in the top-left toolbar.

04

Select the Extracted Extension Folder

In the file picker dialog, browse to your unzipped extension directory containing manifest.json and click Select.

05

Pin Extension & Enjoy Clean Dola Downloads

Click the Extensions puzzle icon in your browser toolbar and pin Dola Remover. Then visit dola.com to automatically remove watermarks and save 1080p clean MP4 videos!

Frequently Asked Questions

Common questions regarding installation, safety, and using the Dola Video Watermark Remover Extension.

01 What is the Dola Video Watermark Remover Extension?
It is a lightweight, open-source browser extension designed specifically for Dola AI (dola.ai). It automatically strips video watermark overlays and provides a 1-click button to download clean HD MP4 files directly from your browser.
02 Is this extension completely free and safe to install?
Yes, it is 100% free and private. The extension contains no advertisements, no tracking analytics, and requires zero user registration. All operations execute purely locally in your browser.
03 Why do I need to install it via Developer Mode?
Installing via "Load unpacked" allows you to run the extension immediately without waiting for Web Store review cycles. It also gives you complete visibility into the source code files for 100% transparency.
04 Does it cause blurry smudges or lower video quality?
No! Unlike AI inpainting tools that smudge pixels, this extension captures the unadulterated high-definition source video stream directly from Dola's media pipeline, maintaining 1080p quality and original audio.
05 Which browsers are compatible?
The extension runs on all Chromium-based desktop browsers including Google Chrome, Brave, Microsoft Edge, Opera, Arc, and Vivaldi across Windows, macOS, and Linux.
06 How do I update the extension in the future?
Whenever an update is released, simply download the latest dola-watermark-remover.zip, replace the files in your existing extension folder, and click the refresh icon on the extension card in chrome://extensions.
