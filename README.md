## 🛠️ How to Install Manually

1. Download `dola_watermark_remove.zip` from the website or GitHub releases.
2. Unzip the archive into a folder on your computer.
3. Open `chrome://extensions` in your Chromium browser (Chrome, Brave, Edge).
4. Turn on **Developer mode** in the top right corner.
5. Click **Load unpacked** and select the extracted extension directory.
6. Open [dola.com](https://dola.com) to start downloading clean videos!
